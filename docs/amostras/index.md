Todas as amostras desta seção documentam o **Estoque Simples**, um produto fictício criado para este portfólio: uma API e um painel web de controle de estoque para pequenas lojas.

Usar um produto fictício me permite mostrar o processo completo, da arquitetura da informação à revisão final, sem expor documentação de clientes ou empregadores.

Cada amostra cumpre uma função diferente para o leitor:

- [Cadastre seu primeiro produto](./tutorial-primeiro-produto.md) é um **tutorial**: ensina quem está começando, passo a passo, até um resultado concreto.
- [Exportar o inventário em CSV](./exportar-inventario-csv.md) é um **guia de tarefa**: resolve um objetivo específico para quem já conhece o produto.
- [POST /produtos](./referencia-post-produtos.md) é uma **referência**: descreve o endpoint de forma completa e fácil de consultar.
- [Mensagens de erro reescritas](./mensagens-de-erro.md) mostra **revisões de texto de interface**, com o raciocínio por trás de cada mudança.

No topo de cada página há uma ficha com o público, o problema e as decisões que tomei.
